# ویرا سیستم | Vira Systems
دموی فروشگاه آنلاین لپ‌تاپ و تجهیزات دیجیتال، با HTML/CSS/Vanilla JavaScript و مناسب GitHub Pages.

## صفحات
- `index.html` خانه
- `shop.html` فروشگاه با فیلتر برند، پردازنده، حداقل رم، سقف قیمت و مرتب‌سازی
- `product.html` جزئیات محصول با تب مشخصات و Scroll Storytelling
- `compare.html` مقایسه زنده ۲ تا ۳ لپ‌تاپ
- `guide.html` راهنمای انتخاب سه‌سؤالی
- `blog.html` مجله
- `cart.html` سبد خرید متکی به localStorage
- `contact.html` تماس با ما
- `404.html` صفحه خطا

## اجرا
فایل `index.html` را باز کنید یا کل پوشه را روی GitHub Pages منتشر کنید. برای عملکرد درست مسیرها، همه فایل‌ها و پوشه‌ها را با هم نگه دارید.

## نکات دمو
- نام محصولات و برند Vira فرضی‌اند؛ از نام و لوگوی رسمی سازندگان واقعی استفاده نشده است.
- قیمت‌ها و مشخصات فنی نمونه‌اند و برای فروش واقعی مناسب نیستند.
- تصاویر از Unsplash بارگذاری می‌شوند و برای نمایش آن‌ها اتصال اینترنت لازم است.
- سبد خرید در مرورگر و با localStorage ذخیره می‌شود.
- فرم تماس و ادامه پرداخت نمایشی‌اند؛ برای استفاده واقعی باید به بک‌اند، سرویس فرم و درگاه پرداخت متصل شوند.
- برای استفاده تجاری، تصاویر، قیمت‌ها، اطلاعات تماس، قوانین فروش و جزئیات فنی را جایگزین و راستی‌آزمایی کنید.
